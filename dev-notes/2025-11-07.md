### 1. Security Fix [DONE]
- **Changed**: `allowInsecure` default from `true` -> `false` in `Axon.new()`

## Technical Decisions

### Keep `https` Import
**Decision**: Keep Node.js `https` import for `allowInsecure` option
**Reasoning**:
- Built-in Node.js module (no extra dependencies)
- Common developer need during local development
- Secure by default with clear warnings
- Used only in one place: creating HTTPS agent for self-signed certs

### Package Naming Analysis
**Checked alternatives**:
- [X] `axon` - taken
- [OK] `axios-fluent` - available (CHOSEN)
- [OK] `fluent-axios` - available
- [X] `axios-chain` - taken (v0.0.0, abandoned)
- [X] `axios-builder` - taken (active)
- [OK] `axify` - available
- [OK] `axios-flow` - available

**Selection criteria**:
1. Availability on npm
2. Clear purpose/intent
3. SEO/searchability
4. Professional tone
5. Easy to type/remember
6. Pattern match with successful packages

### Version Number
**Chose**: `0.1.0` (not 1.0.0)
**Reasoning**:
- Beta/initial release indicator
- Allows for breaking changes before 1.0
- Signals "production ready but may evolve"
- Common practice for new packages
